# 中考诊断台（赤峰 · 2027）

给赤峰市初三学生用的中考分模块诊断网站。按内蒙古自治区统一命题的科目和分值，把每科拆成若干模块，每个模块用自适应选择题定位到四个层级之一：基础、中档、较难、压轴。家长导入成绩后能看到预估总分、离赤峰二中等目标还差多少、最值得先补的模块、薄弱知识点和全部错题解析。

纯静态网站，不依赖任何外部 CDN、字体或接口，在国内无需翻墙即可使用。

## 怎么用

- **学生**：打开网站，写上名字，选模块或“整科诊断”开始。做完后把成绩码复制到微信发给家长。“我的结果”里有包含全部记录的汇总成绩码。
- **家长**：打开“家长”页，粘贴成绩码（一次可粘贴多条），即可看到报告。作文、书面表达、实验操作、体育、地理+生物等网站测不了的分数在报告里手动填写。

## 目录

- `site/`：网站本身（GitHub Pages 发布这个目录）
  - `content/subjects.js`：科目、模块、分值、层级与目标分数线
  - `content/*.js`：各科题库（原创题，仿内蒙古中考风格）
  - `app.js`：诊断引擎与页面；`sync.js`：成绩码与可选的云同步；`config.js`：配置
- `cloud/scf/index.mjs`：可选的成绩同步云函数（腾讯云国际站，香港）
- `tools/validate.mjs`：题库校验（`node tools/validate.mjs`）
- `tools/build.mjs`：生成 `dist/中考诊断台.html` 单文件版（可直接微信发送）

## 自动同步（可选）：腾讯云国际站 · 香港

不开通也能用（成绩码）。开通后，学生每做完一个模块自动上传；没连上时先存在本机，下次打开网站自动重发，同时照常显示成绩码。家长页输入家长密码即可拉取。

1. 在 tencentcloud.com 的 COS 新建一个**私有**存储桶，地域选中国香港（ap-hongkong）。
2. 在 SCF 新建 Node.js 18 及以上的事件函数，地域同样选香港：
   - 运行环境选 Node.js 20，把 `cloud/scf/index.mjs` 的内容粘贴到在线编辑器的 index.mjs，执行方法为 `index.main_handler`，超时时间设为 30 秒。
   - 设置环境变量 `BUCKET`、`REGION`、`WRITE_KEY`、`PARENT_PASS`，可选 `ALLOW_ORIGIN`。
   - 绑定一个对该存储桶有读写权限的运行角色。
   - 开启函数 URL（公网访问，不鉴权）。
3. 在 `site/config.js` 填写 `cloud: { url: "函数 URL", key: "与 WRITE_KEY 相同" }`。家长密码不要写进网站。

`WRITE_KEY` 写在网站代码里，是公开的，只用来挡掉随手乱发的请求；`PARENT_PASS` 才保护成绩的读取。
